# File Integrity Checker

A simple C++ cybersecurity tool that uses SHA-256 hashing to check whether a file has been modified.

## Features

- Calculate SHA-256 hash
- Save file hash
- Load saved hash
- Verify file integrity
- Detect file changes
- Basic input and error handling

## Technologies

- C++
- OpenSSL
- SHA-256

g++ main1.cpp -o main1 -lcrypto
